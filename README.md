# React To-Do App

A simple and responsive To-Do List application built with **React**.

## Live Demo

[View Live Demo](https://react-todo-app-33dv.vercel.app/)

## Features

* Add new tasks
* Edit tasks
* Delete tasks
* Mark tasks as completed
* Filter tasks
* Save tasks using LocalStorage
* Tasks remain saved after refreshing the page
* Responsive design

## Technologies

* React
* JavaScript
* Material UI (MUI)
* Context API
* LocalStorage
* CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/Osama-dev20/react-todo-app.git
```

Install dependencies:

```bash
npm install
```

Start the project:

```bash
npm start
```
